# Mongol OS Official Website

Source repository for the official Mongol OS website: [mongol-os.org](https://mongol-os.org).

Mongol OS is a Mongolian Linux operating system based on Debian. This website shares project information, downloads, documentation, and ways to participate with users in Mongolia and around the world.

## For contributors

Contributions to the website are welcome. You can help by improving Mongolian or English copy, fixing a website issue, improving accessibility, updating project information, or reporting a problem.

Before opening a pull request:

1. Check existing issues and pull requests to avoid duplicating work.
2. Keep changes focused and explain the user-facing reason for the change.
3. Use the language and terminology already used in the relevant page. When editing translated content, keep the meaning aligned across languages.
4. Check that links work and that pages remain readable on both mobile and desktop screens.
5. Include screenshots for changes that affect page layout or appearance.

For larger changes, open an issue or discussion first so contributors can agree on the approach.
